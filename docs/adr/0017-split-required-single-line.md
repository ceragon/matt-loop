# 会话起始 skill 命令行超体积/多行拒发（split_required）

## 背景

#61 实证：调用方把「会话起始 skill 命令＋正文」一次发进 claude 执行者会话时，
Claude Code 把超体积或多行的粘贴折叠成 `[Pasted text #N +M lines]` 块。块内行首
斜杠命令只是文本、不触发展开，skill 不被调用；模型看到正文后改调 Skill 工具，又被
skill 的 `disable-model-invocation` 挡回。结果是连跑三轮空转，每轮白烧一次抽取，
调用方在发送前没有任何机械信号知道这段提示词会被折叠。现有 `reset_required` 闸
（ADR-0004）只管重置口径（turn>0＋none），不管提示词形态。

#61 复现表（放行 id 见 #61）：

| 提示词形态 | 结果 |
| --- | --- |
| 22 行：命令＋正文一次发 | 折叠成 pasted text 块，slash 不展开，失败 |
| 24 行：命令＋空行＋正文一次发 | 折叠成 pasted text 块，slash 不展开，失败 |
| 2 行：命令＋约 1400 字中文长行 | 折叠成 pasted text 块，slash 不展开，失败 |
| 1 行：只有命令 | slash 正常展开，skill 被调用，成功 |

## 证据

阈值证据出自 Claude Code 2.1.331（BUILD_TIME 2026-11-23T15:17:48Z，
GIT_SHA 3c6b6136f768e339d752df27c19f2d6b513e2bd6）原生二进制内嵌 JS，
只引版本号与字节偏移（公开仓库卫生红线，不写本机路径）：

- 折叠阈值常量 800 @323578697；
- 粘贴处理判定式（长度>800 OR 换行数>max(0,min(rows-10,2))）@343663417；
- 换行计数 @314225122；行阈值 @343663398；
- bracketed paste 解析 @328115541 → 派发 @328864473 → onPaste @329283606；
- 超长 key 旁路汇入同一判定 @329281130；
- 折叠后跳过 slash 执行的提交路径 @344302784。

2.1.241/293/325 同逻辑。herdr hc 0.1.22 的发送语义是「paste text and press Enter」，
hc-core 二进制含 bracketed paste 标记字面量。

**矛盾如实记录**：#61 报告「1/2/4 行能过」与换行分支（≥3 换行即折叠）不一致。
候选解释：hc 探测不到 pane 的 bracketed-paste 模式时退回裸文本／视觉折行被误数成行／
证据来自非 claude 目标／「能展开」指已折叠块可展开。四者均未实测，不掩盖；
`hc send` 实际注入模式（bracketed paste vs 裸文本回退）的实测本期不做。
判定式 C（命令轮严格单行）对全部候选解释免疫——单行短命令无论走哪条注入路径都展开。

## 决定

1. **触发口径**：复用 ADR-0004 的会话起始 skill 触发器（任意行首、允许行前空白、
   命令后须非词字符且非连字符、implement-spec 优先报长名、五 skill 清单不变），
   不新增触发器。「正文在前、命令在后」同样被保护，两套闸口径不漂移。
2. **判定式 C**：命中触发器且（归一化后 UTF-16 码元数 >700 **或** 含内部换行）即拒。
   命令轮严格单行，单行长参数无豁免。尾换行豁免取定案 A：内部换行＝剥掉尾部换行
   （含连续多个）后仍含换行；体积按含尾换行的归一化全文计（忠实于实际发送物）。
3. **计量与闸值**：归一化复刻 Claude Code 2.1.331 粘贴处理（CRLF/CR→LF、tab→4 空格）；
   UTF-16 码元数＝UTF-16-LE 编码字节数除以 2（中文 1、emoji 2）。闸值 700＝上游实证
   折叠阈值 800 留余量；硬编码常量 `SPLIT_MAX_UTF16`、零旋钮（无 env、无旗标），
   与 READ_LINES 同等待遇；常量注释钉上游版本与实证偏移，改值须重验上游版本。
4. **适用范围**：不分 agent kind、不做 kind 判定、不靠 `--expect-proc` 旁证，脚本保持
   零 agent 映射。与 `--reset` 独立：重置前置是单独发送的字面命令，主任务仍是一整段
   粘贴，带重置不豁免形态闸；新鲜路径（创建/复活/重建）同样过闸，新会话不是折叠的逃生门。
5. **闸位置与优先级**：静态纯文本判定，位于 `duplicate_release` 之后、工具查找／
   `hc get`／领养之前，零发送零副作用。优先级链：参数类错误 → `duplicate_release` →
   `split_required` → 一切目标态错误（含 `not_idle`/`identity_mismatch`/`reset_required`）；
   与 reset 闸双命中先报 split（先修形态、再谈重置）。退出通道全复用既有 DispatchError
   机械（stdout 一行 JSON、result.json、notify 与 `reset_required` 同构），零新字段、
   零新 phase；message 带 skill 名、行号与具体原因（换行／码元数与闸值，双命中并列）。
6. **重试语义**：改提示词文件为单行命令（只带短参数）后**同 id** 重试（拒发不消耗
   放行 id）；长正文经用户重新放行、**新 id** 下一轮发。命令轮与正文轮各自独立放行，
   每一轮全文都经用户授权，拆轮不绕过放行纪律。
7. **文档纪律**：SKILL.md（description／Step 1／「会话起始 skill」节）与 REFERENCE.md
   （退出码清单／错误表／预检顺序／纪律段）同步；ADR-0004 加补记指向本 ADR。
   GLOSSARY.md 与 CLAUDE.md 不动：闸值/退出码/归一化是机械细节非领域词汇；既有
   「折叠」词条指回读折叠标记（ADR-0013），与粘贴折叠是两处机械，不新增词条避免混淆。

## Considered Options

- **(b) 自动拆发**（`--split-first-line`，同一放行内先发首行再发正文）：两次回声的
  锚点/断轮复杂度本期不进脚本，留到调用方嫌两轮麻烦时再做。
- **(c) 纯纪律**（只写 SKILL.md 不加机械闸）：#61 三轮空转实证纪律挡不住，无兜底。
- **纯体积闸**（只判 >700）：小体积多行粘贴同样被折叠（换行分支），漏放。
- **体积 OR 换行数>2**（照抄上游判定式）：行阈值 max(0,min(rows-10,2)) 随 pane 高度
  漂移，不可钉；命令轮严格单行才是稳定口径。
- **仅首行触发**：与 reset 闸的任意行首口径漂移，「正文在前、命令在后」漏保护。
- **仅 claude 目标生效**：需要 kind 判定，破脚本零 agent 映射；跨目标行为不一致。
- **精确 800**：无余量，上游阈值微调即穿透；700 留余量且对命令轮（短参数）足够宽。
- **env 旋钮/旗标可调闸值**：判定口径不稳定、可被静默打开，与零旋钮纪律冲突。

## Consequences

- 命令轮恒以单行短提示词到达，slash 命令恒展开、skill 被真正调用；形态错误在本地
  零成本定谳（零发送、零副作用、id 不消耗），不再烧轮次白跑抽取。
- 既有测试面 4 处多行触发夹具改单行（target-model 2 处、get-or-create 2 处），
  断言同步；reset 纪律套件全单行夹具零改动。新套件 `test_dispatch_split_required`
  14 例钉外部行为（退出码/stdout/result.json 形状/台账/hc 调用数）。
- 放行次数增加（命令轮＋正文轮各一次），但每轮全文仍经用户授权，放行纪律不打折。
- 闸值 700 是留余量的实证值、非上游保证；上游折叠逻辑变更须重验版本后改常量。
- 四份 skill 副本（仓库与三份安装，分布在不同机器）逐字节同步，跨机器口径不漂移。
